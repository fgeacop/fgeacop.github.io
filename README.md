# FGEA Community of Practice

Standalone website for the Future Generation Enterprise Architecture Community of Practice.

## Local preview

Run a static server from the repository root:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Deployment

Pushes to `main` deploy automatically through GitHub Actions. The public site is available at:

<https://fgeacop.github.io/fgea/>
